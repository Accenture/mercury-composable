**The adversarial review round (4 lenses → per-finding refutation; 16 confirmed / 2
refuted) was decisive again — durable lessons:**
- **GraalVM `Context.interrupt` is non-destructive and only affects an eval in flight**
  — a deadline landing in a host-code gap between evals is silently consumed and later
  evals run unbounded (empirically probed on polyglot 25.0.2). Sticky cancellation
  (`close(true)`) is the correct watchdog action.
- **`Context.interrupt(Duration.ZERO)` means WAIT INDEFINITELY**, not fire-and-forget —
  calling it from a vertx timer callback would block a shared Netty event loop (and
  every timer on it: flow timeouts, watchers, sendLater). Never run polyglot
  cancel/interrupt on an event-loop thread.
- **A deferred launch must not outlive its flow** — sendLater ids need teardown
  cancellation (also fixed the pre-existing function-task variant).
- **Terminal emission needs CAS arbitration** — a run racing its own deadline emitted
  both terminals, and firstErrorLine would classify a SUCCESSFUL run as failed.
- **The 30s/30s default tie**: the companion safety net beat the watcher's terminal in
  the default config, contradicting the docs' "always receives a terminal" claim.
- **Mutation-testing exposed a vacuous test**: the "no late watcher" test tapped the

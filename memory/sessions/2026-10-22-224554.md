  `switch` with guards (IntelliJ's if-to-switch).

  `assertThrows`, so S5961 counts it, and each line that calls it counts twice.
- **`IRegexpTest`:** a `finds()` helper null-checks the pattern, as `matches()` does. `IRegexp.compile` returns null for a text
  outside I-Regexp.
- **`CompileFlows`:**
  - `validOutputMapping` (complexity 16) gains `addValidatedOutputEntry`, which mirrors the input side and keeps the order of the
    checks;
  - `validForStatement` filters with a stream and ends with `contains`.

- **`JsonPathSource`:**
  - `\d` replaces `[0-9]` in the three patterns;
  - `INDEXES` is `(?:\[\d++])*+`, because S5998 flags a repeated group and each `[n]` is self-delimited;

  - `graphSpans` is a stream.

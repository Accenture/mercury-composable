- **Finding 4, the tag across Kafka.**
  - `InvocationObservers.export(destination, traceId, tracePath)` returns the observers' tags for a message that leaves
    the event bus. It applies the route filter to the destination.
  - `simple.kafka.notification` writes each tag as a Kafka header `x-mercury-tag-<tag>`
    (`KafkaHeaders.OBSERVER_TAG_PREFIX`) and never forwards a stale one.
  - `KafkaFlowConsumer` removes those headers from the flow's `input.header` and restores them on the event at every
    attempt. Each delivery is an incoming hop on `kafka.flow.adapter`, opened and closed on the poll thread, and the
    request into the flow is sent inside it.
  - New tests: `InvocationObserverTest.exportsTheTagsForATransportOutsideTheEventBus`,
    `SimpleKafkaNotificationTest.anObserversTagsCrossKafkaAsHeaders` (a `MockProducer`) and
    `KafkaFlowConsumerTest.eachDeliveryIsAnIncomingHopLinkedByThePublishersTags` (a retry included).
  - Docs: the observability guide, the `minimalist-kafka` guide, the CHANGELOG and RFC-0009.

## The configuration-key audit (Eric: "check the parameters so that they can coexist")

A scan of every `.properties` key, every key the code reads and the configuration reference found two keys that are
both a value and a parent:
- `cloud.connector` / `cloud.connector.health`: a false positive, since the second is a function's route name;
- `scheduler.environment` / `scheduler.environment.store`: real, in the mini-scheduler since 4.12.22 (ADR-0030).

A probe with the real `ConfigReader` showed what happens. When the child is set, in either order,
`getProperty("scheduler.environment")` answers `{store=my.store}`, the text of the child map. `ActiveEnvironment`'s
name check then fails at startup with the misleading "scheduler.environment must be one word…". So no installation can
be setting `scheduler.environment.store` today. The Rust port has no such setting.

Eric: "the mini-scheduler and scheduler-example need the same parameter renaming fix". It is released code, so it goes
in its own PR from main, like the `ManifestReader` fix.

  head with `idleSeconds` as the edge idle allowance AND arms a watchdog with
  the same allowance (one number, so the two never disagree), registers the
  sink via `beginStream`, re-arms on every drained segment, disarms on the
  terminal. Expiry = the single final drain (D4's flagged nuance), then — only
  if the stream did not complete — in-band 408 + `closeStream`. The same
  expiry reclaims abandoned/disconnected clients (the edge drops late writes
  on its own), so the `PendingStreams` slot and keys cannot leak. Capacity
  rejection surfaces as a real HTTP 503 (head not yet committed). One shared
  daemon timer thread; blocking expiry work hops to a virtual thread.

  named write, eof→close(metadata), exception→fail(AppException 500)).

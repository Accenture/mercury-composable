## Investigation findings (durable)

1. **Two independent root causes blocked subgraph suspend/resume**: (a) the Redis key was
   `graph:state:{cid}` — one record per cid globally (domain and parent/subgraph
   collisions, the field's report); (b) GraphExtension invoked the child flow with
   `setCorrelationId(util.getUuid())` and no `correlation_id` header, so
   EventScriptManager's fallback made the subgraph's `model.cid` a random per-call UUID —
   resume could never find a record even with scoped keys.
2. **Event Script already inherited the business cid into sub-flows**
   (TaskExecutor.executeSubFlow stamps `EventScriptManager.BUSINESS_CORRELATION_ID`) —
   R2 is "bring GraphExtension in line", and flow→graph rides the same sub-flow path.
3. **`error` was ALWAYS a reserved alias** — platform-core `MiniGraph.RESERVED_NAMES`
   (`input, output, model, response, result, parameter, none, next, api, error`) rejects
   it at node creation, so the new namespace has **no breaking edge** and needed no new
   gate rule (my draft validator rule was unreachable dead code — removed; the gate
   test pins the import-level rejection instead).
4. **`exception=` already spanned the whole family** including graph.task (pinned by
   unit-test-task-4) and handler-with-continuation (unit-test-join-retry's retry loop) —
   the field's "please validate" items were both already true. The real gap: only
   `{node}.status/.error` were staged, forcing per-fetcher handler clones.
5. **`inspect` is a raw state-machine viewer** (no alias validation), so `inspect error`
   worked by construction the moment staging landed — no virtual node needed (Eric's
   mid-session question).
6. **Test-fixture gotcha re-learned**: a graph.math IF/THEN/ELSE triad must be ONE
   multi-line statement string (not three array entries), and a dynamic variable on a
   possibly-absent key needs the `=` probe guard (`text(={model.path.type})` compared to
   `'=suspended'`) — a bare `{model.x}` on a missing key renders "null" and the
   expression engine throws `Unknown identifier: null`. The orchestrator fixture now
   demonstrates the taught idiom.
7. The mock MDM profile throws `IllegalArgumentException` → HTTP 400 for unknown ids;
   its `x-exception` header simulates `AppException(401)` — used to give the two
   error-context test cases distinct codes (401 http vs 400 task).

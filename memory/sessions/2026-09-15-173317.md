## What happened

### 1. MsgPack cache value (Eric authored; I reviewed + documented) — commit `a77283c9`

Eric refactored the example's cache value from an `EventEnvelope` holder
(`new EventEnvelope().setBody(map).toBytes()` / `EventEnvelope.of(bytes).getBody()`) to a **plain
MsgPack-packed Map** (`msgPack.pack(map)` / `msgPack.unpack(bytes)`) in `ProfileEncoder`,
`ProfileDecoder`, and `ProfileCacheL1` (L1 inline). Reasons: (1) **efficiency** — the value is just
the key-values, needs none of the envelope id/headers; (2) **Rust interop** — the compacted
`EventEnvelope` encoding is a Java-side wire format the Rust port does not read, and storing the
envelope as ordinary key-values would waste space; plain MsgPack key-values is compact AND the form
every language pack reads.

**Correctness verdict — sound.** Verified: `MsgPack.pack`/`unpack` build a fresh packer/unpacker +
local `ByteArrayOutputStream` per call (no instance state) → the `static final MsgPack` shared across
10–20 VT instances is thread-safe, and it matches platform-core's own pattern (`EventEnvelope.java:30`
holds a `static final MsgPack`). Interop preserved by construction: all three layers pack/unpack the
same Map → identical bytes; `crossLayerInterop` (POST L1 → GET L2) stays green. Miss handling correct
(`bytes.length > 0` guard before unpack). **Caveat (non-issue for the demo):** `MsgPack.unpack`
unwraps a map carrying the `_T`/`_D` payload sentinels — a profile with a field literally named `_T`
would be misread; realistic profiles never collide and `pack(Map)` writes no sentinel, so the
round-trip is clean.

Doc updates to match the switch: README holder section (renamed "a MsgPack-packed Map"; **corrected the
old claim that the EventEnvelope format is what enables cross-language interop — it's the reverse**,
now a "why plain MsgPack" note with Eric's two reasons), the graph node purposes (profile-cache.json),
the L2 flow descriptions (l2-profile.yml), and the `ProfileEncoder`/`ProfileCacheL1` Javadocs; removed a
stray double blank line in `ProfileEncoder`. `MethodActionMapper` got `final` on its two locals (Eric's
polish). Example tests 4/4 green.

## What was done (RFC-0010 on #577's branch)

- **The rule.** Substitution first, then parsing, in both layers and on both engines: Event Script's `{model.key}` and
  `[model.i]`, and the knowledge graph's `{namespace.key}`. The flow-compiler refusal is dropped.
- **The check, so that the rule cannot inject.** A substituted value is checked where it lands:
  - **in a path,** a plain key path (names joined by dots, with RFC 9535 shorthand and hyphens) or an integer index;
  - **inside a string literal the author wrote,** escaped: its quote and its backslash, and never quoted again, because Event
    Script inserts text raw, so a flow author writes `'{model.team}'`;
  - **bare inside a filter,** a text value becomes a literal, as the graph does today;
  - **a list or a map** cannot be substituted, because RFC 9535 has no array or object literals.
  A value that fails its check fails the mapping by name. Every value a working flow or graph substitutes today gives the same
  query.
- **A second gap, recorded in the RFC.** `GraphLambdaFunction.escapeVar` escapes the quote but not the backslash. So a value
  that ends with `\` escapes the closing quote, and the literal runs on into the rest of the query.

## Decisions

- **The panel edits path, type, requiredness, description and example; every other keyword of the subset is a read-only chip carried
  through Save unchanged** - the node editor edits those. A panel that offered every keyword would be a second schema editor; one that
  dropped them would lose declarations silently (the partial-gate lesson). Eric's to confirm at promotion.
- **A Save re-sends the node's other properties as the node editor does**, because the engine clears the property set on update; the
  command is built by the existing builder, the one serialization boundary. A node the editor cannot represent is refused by name.
- **An untyped row with no description is not declared** (an empty schema cannot travel through the grammar), so it stays
  `discovered` after a Save - the panel declares what the user typed, nothing more.
- **A reload that answers after a row was edited is dropped; an explicit Reload discards the edits** (found by a test that edited
  during an in-flight reload - a real race, not only a test artefact).

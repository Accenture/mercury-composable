**Title:** The Playground's graph view widens a node whose text would wrap heavily - lock-step with Rust

## Context

A contributor's request, with a screenshot of a text-heavy graph in the Graph tab: every node was 240 px wide, so a node with
long mapping lines wrapped each value onto three or four lines and grew taller than the screen. "Increase the width of the
nodes if it causes a lot of word wrapping"; slightly wider nodes already made that graph easier to read. Branch
`feat/playground-node-width-by-wrapping` in both repositories.

## What was done

- **The width rule** (`webapp/src/utils/graphTransformer.ts`, `estimateNodeWidth` / `layoutNodeWidths`): a node starts at
  240 px and widens in 40 px steps, up to 480 px, while its property rows would wrap onto more than 1.5 lines per row on
  average. The line estimate already existed for heights (22 characters per line at 240 px); it is now a function of the width:
  the value column is the width minus 86 px (borders, body padding, the 60 px label column, its gap), at one character per 7 px.
  Both numbers were measured in the browser before the change: the value column was 154 px at 240 px, and the 12 px text
  wrapped at word boundaries at about 7 px per character. Heights are estimated at the node's own width.
- **Columns** (`computeLayout`, `columnOffsets`): every flow node in a column takes the width of the column's widest node, and
  a column starts 120 px after the previous one ends. The first version left narrower nodes at their own width at the column's
  left edge. Tutorial 5's crossing test then failed with one intrusion: the edge from `dictionary` to `person-name` ran across
  the part of the wider `fetcher-1` that sticks out beside `dictionary`. The intrusion scoring only checks nodes in the columns
  an edge skips, so a shared column width is the simplest rule that keeps that scoring exact. Segregated nodes (no
  connections) keep their own width and sit 120 px apart. The candidate geometry, the bezier y-range test and the intrusion
  relief use per-node widths. Thumbnail mode keeps every card at 240 px.
- Docs: `webapp/docs/graph-view.md` (step 7 Pixels, step 9 segregated rows, a width paragraph with a worked example, heights
  at the node's width); CHANGELOG Unreleased Changed 2.
- Bundle `index-CWNizJaH` → `index-QRtKBTvK` by `npm run release:all`. The vendor chunks and the CSS were rebuilt byte for byte
  under Node v26 (`npm ci` first: `node_modules` was empty), and the Rust help mirror changed nothing.

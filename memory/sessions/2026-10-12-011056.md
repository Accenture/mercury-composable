## Decisions

- A null range answers null, never the default: the default documents an open end; a missing band has no bounds; the null-source
  rule leaves the target unset, which the fixture's open-end case already relied on.
- The lookup value must be a number or text on every table kind, a boolean included - one rule for the whole surface; `f:lookup` is
  unchanged (a boolean key is a legitimate rule there).
- The quote rule is symmetric and follows the YAML convention: the other quote character is ordinary text inside a bound, a bound's
  own never (use the other style). The timestamp shape stays declared, not gated ([[clean-knowledge-design-over-engine-coverage]]).

## Decisions Made

- Download mirrors `export graph as`: the graph id follows the engine's file-name rule, the extension is always `.json`, and the root node's name in the FILE becomes
  the id while the live graph is untouched (stated as an assumption in the checkpoint; the help page and the dialog say it).
- An import over a loaded graph asks first (a dropped file can be an accident, and an import cannot be undone); a bare session imports straight away.
- The UI validates simply and the engine validates again with its own importer; CompileGraph stays the quality gate (Eric's instruction, and
  [[clean-knowledge-design-over-engine-coverage]]).
- A graph file import travels like a command, the mock-upload shape, so a shared session stays one draft ([[playground-three-step-run-controls]]).
- The hook toasts errors only: the engine's console line is the success signal and already refreshes every member's view; a success toast would double the
  "Graph imported" toast.
- The "Graph Data (Raw)" tab is "Raw" (the `graph-data` tab id and its persisted selection are unchanged).
